# ToDo

A to-do list web app (Home, Calendar, Categories). TypeScript, Expo SDK 57 with Expo Router, Firebase (Cloud Firestore), deployed on Netlify. No accounts: a list is opened by a unique username.

Docs: [`docs/PLAN.md`](docs/PLAN.md) (phased plan) · [`docs/ERD.md`](docs/ERD.md) (data model) · [`docs/decisions.md`](docs/decisions.md) · [`docs/mockup-coverage.md`](docs/mockup-coverage.md) · [`docs/skills.md`](docs/skills.md).
Design mockups: `../ToDo_Mockup/`.

## Commands

```bash
npm install
npm run web          # dev server for the web app
npm test             # unit and component tests
npm run typecheck    # tsc --noEmit
npm run lint         # expo lint
npm run db:smoke     # quick check against the Firebase project in .env.local
npm run test:firestore  # full repository contract against the real project (slow, creates and deletes ct... users)
```

Deploy: Netlify builds from `netlify.toml` (base `ToDo`). Set the three `EXPO_PUBLIC_FIREBASE_*` variables in the Netlify site settings.

Firebase setup: copy `.env.example` to `.env.local` and fill in the three values; deploy the rules with `npx firebase-tools deploy --only firestore:rules`.

Install Expo-managed packages with `npx expo install <package>`. Run typecheck, lint and tests before finishing any change. Typed routes are generated by the dev server: start it once after adding a route, before running `npm run typecheck`.
